# 🤖 Telegram-бот «Космопарк» — гид по выставке

Бот-гид для посетителей выставки «Космопарк». Помогает ориентироваться в зонах,
выдаёт технику безопасности и предоставляет информацию об экспонатах.

Разработан на C# с использованием Telegram Bot API.

---

## 🎯 Задача

Посетителям выставки нужно было быстро получать информацию о зонах и экспонатах.
Бот автоматизировал эту задачу: вместо бумажных буклетов — интерактивный помощник в Telegram.

---

## 🛠️ Функционал

Бот поддерживает команды для всех зон выставки:

- `/Menu` — главное меню со всеми зонами
- `/Kacca` — информация о кассе
- `/Openspace` — Открытый космос (11 зон с экспонатами)
- `/SHPK` — Штаб подготовки космонавтов
- `/MKS` — Международная космическая станция
- `/Giroskop` — техника безопасности и информация о гироскопе
- `/MK` — мастер-классы
- `/VR` — VR-зона
- `/Tesla-show` — шоу Теслы

Бот выдаёт:
- Описания зон и экспонатов
- Технику безопасности для активностей
- Изображения с информацией
