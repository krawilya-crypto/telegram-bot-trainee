# Telegram-бот для автоматизации обучения стажёров

Бот на C# для автоматизации процесса адаптации новых сотрудников. 
Разработан в рамках работы в ООО «Мирей Роботикс» для сокращения времени онбординга.

## 🎯 Задача

Руководители тратили время на выдачу учебных материалов новым стажёрам вручную. 
Нужно было автоматизировать: выдачу материалов, контроль прогресса, напоминания о дедлайнах.
